# Plano rápido — Serviço de Chatbot de WhatsApp com IA (renda paralela)

Meta: fechar o **1º cliente pagante em 7 dias**, sem gastar com anúncio.

## 1) Nicho pra atacar primeiro
**Clínicas de estética / odontológicas** (ou salão/barbearia se quiser algo mais fácil de entrar).
Por quê: recebem MUITA mensagem repetida no WhatsApp (preço, horário, agendamento),
perdem cliente quando não respondem rápido, e têm dinheiro pra pagar.
> Dica: comece por um negócio que você JÁ conhece (seu, de amigo, de família). Indicação fecha mais rápido que porta fria.

## 2) A oferta (uma frase)
> "Coloco uma IA no WhatsApp da sua clínica que responde os clientes na hora,
> tira dúvidas e agenda horário — 24h por dia, até quando você está ocupado."

O gancho de venda: **"quantos clientes você perde por não responder o WhatsApp a tempo?"**

## 3) Preço (simples)
- **Setup:** R$ 800 a R$ 1.500 (nos 2 primeiros clientes, pode fazer R$ 500 pra montar portfólio).
- **Mensal:** R$ 200 a R$ 400/mês (manutenção + IA + ajustes) → isso é a **receita recorrente**, o ouro.
- Oferta de lançamento fácil de vender: **R$ 497 setup + R$ 197/mês**.

## 4) Como fechar o 1º cliente em 7 dias
- **Dia 1** — Liste 10-15 negócios com quem você tem ALGUMA ligação (warm, não frio).
- **Dia 2** — Monte um **DEMO funcionando** (um chatbot de exemplo no WhatsApp). Isso é o pulo do gato: **mostrar funcionando** vende 10x mais que explicar.
- **Dia 3-4** — Aborde os contatos: "montei uma IA que atende WhatsApp sozinha, fiz uma demonstração — quer ver funcionando?" Manda o demo.
- **Dia 5-6** — Ofereça montar pra ELE. No primeiro, pode fazer barato/grátis em troca de **depoimento + estudo de caso**.
- **Dia 7** — Fecha o 1º (pagante, ou grátis-por-depoimento pra destravar).

Depois: cada cliente satisfeito **indica** outro. É assim que escala sem anúncio.

## 5) Ferramentas pra montar rápido
- **Conectar o WhatsApp:** Evolution API ou Z-API (rápidas de plugar um número no Brasil) — ou WhatsApp Cloud API oficial (Meta).
- **O cérebro:** API da Anthropic (Claude) — o MESMO que você já usa no Vonai.
- **Sem código (alternativa):** Typebot (grátis, open source) para o fluxo + IA.
- Você já domina esse stack do Vonai — é reaproveitar.

## 6) Por que isso é bom pra você
- Caixa rápido, sem estoque/frete/devolução (nada de burocracia de produto físico).
- Recorrência (mensalidade) = renda previsível.
- Usa e afia as MESMAS habilidades do Vonai (vender + programar com IA).
- Formalize simples com **MEI** (nota de serviço).
