## Checklist de deploy (nesta ordem)

1. **Supabase → SQL Editor → `migracao_2026-08-21_trial_7_dias.sql` → RUN.** Muda os dois
   triggers para 7 dias e garante as colunas `criado_em`, `whatsapp`, `emails_enviados`,
   `dias_ativos` em `progresso`. Sem isso o site promete 7 dias e o banco dá 2.
2. `publicar.bat` (git push → Vercel).
3. **Vercel → Environment Variables** (opcionais, mas é o que liga cada canal):
   - `EMAIL_REPLY_TO` — para onde vão as respostas dos e-mails (padrão: igormelo47@gmail.com).
   - `WHATSAPP_API_URL` + `WHATSAPP_API_TOKEN` (+ `WHATSAPP_API_HEADER` se o provedor não usar
     `Authorization: Bearer`). Sem as duas, o WhatsApp fica desligado e nada quebra.
     Provedores que aceitam `POST {phone, message}` direto: Z-API (header `Client-Token`),
     Evolution API, UltraMsg. Para a Cloud API oficial da Meta é preciso um adaptador
     (template aprovado) — ver comentário em `lib/whatsapp.ts`.
4. Testar: criar conta nova → fazer o treino → no fim deve aparecer "Que horas eu te lembro?"
   → escolher → "Topa apostar 7 dias?" → "Apostar" → Home mostra "Aposta de 7 dias: dia 1 de 7".
5. Vercel → Cron → rodar `/api/send-reminders?turno=noite` manualmente e conferir no JSON de
   resposta os campos `whats`, `porTipo.d2`, `porTipo.d3`.

## O que NÃO foi feito (precisa de decisão ou de trabalho nativo)

- **Push nativo no iOS (APNs).** O app da App Store é Capacitor sem plugin de push; web push não
  existe lá. Enquanto isso, WhatsApp e e-mail são os canais do iPhone.
- **Trial com cartão / paywall rígido** (RevenueCat no iOS, Kiwify na web): mudança de
  configuração de produto nas lojas, não de código. Recomendação no plano de retenção.
- **Primeira correção por voz em < 3 min após o diagnóstico**: o fluxo atual já cai no treino
  guiado; uma "conversa de 60 s" logo após o nivelamento é a próxima mudança de produto a
  fazer — é onde 57% desistem hoje (antes de terminar a 1ª lição).

## Cobrança com cartão na entrada — o que falta fora do código

- **iPhone:** em App Store Connect, nos produtos mensal e anual, criar **Introductory Offer → Free trial → 3 days**. A RevenueCat repassa sozinha; o botão "Começar 3 dias grátis" já chama `VonaiNative.subscribe('mensal')`. A Apple cobra automaticamente no dia 3 se não cancelar — é exatamente o fluxo da Lucida.
- **Web/Android (Kiwify):** a Kiwify não guarda cartão para cobrar depois. Hoje o botão libera o trial de 3 dias sem cartão e o paywall rígido aparece no dia 3. Para ter cartão na entrada também na web, trocar por **Stripe** (assinatura com `trial_period_days: 3`) — próxima etapa, ~1 dia de trabalho.
